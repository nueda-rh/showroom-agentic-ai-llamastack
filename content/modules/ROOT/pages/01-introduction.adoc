= はじめに (Introduction)

Red Hat OpenShift AI 上での *Llama Stack*、*LangGraph*、*Langfuse*、*Langflow*、*FastAPI*、*FastMCP* を使用した Agentic AI アプリケーション構築に関するハンズオンワークショップへようこそ。このラボシリーズでは、最初の Llama Stack インスタンスのデプロイから、Model Context Protocol (MCP) を通じてエンタープライズシステムと連携する AI エージェントの構築までを扱います。

== 学習内容 (What you'll learn)

**Llama Stack のデプロイと探索 (Deploy and explore Llama Stack)**:: OpenShift 上に Llama Stack ディストリビューションをデプロイし、その包括的な API 機能を探索して、ネイティブな Response API を含む複数の推論インターフェースを通じて言語モデルと対話します。

**RAG 機能の実装 (Implement RAG capabilities)**:: Llama Stack 組み込みのベクトルストア、埋め込みモデル、ファイル検索ツールを使用して検索拡張生成 (RAG) システムを構築し、自社のドキュメントに基づいて AI レスポンスを生成させます。

**セーフティガードレールの適用 (Apply safety guardrails)**:: AI アプリケーションがエンタープライズレベルのセキュリティおよびコンプライアンス要件を満たすよう、コンテンツモデレーションとセーフティシールドを実装する方法を学びます。

**Web 検索ツール (Web Search Tool)**:: Tavily を活用してコンテキストを拡張し、モデルのナレッジカットオフや制限された学習データを補完します。

**MCP を通じたビジネスシステムの統合 (Integrate business systems via MCP)**:: Llama Stack および LangGraph エージェントをバックエンドマイクロサービスと接続する Model Context Protocol (MCP) サーバーをデプロイ・登録し、AI が顧客データ、金融取引、その他のエンタープライズ機能にアクセスできるようにします。

**自律型エージェントの構築 (Build autonomous agents)**:: ネイティブの Llama Stack Client と LangGraph のような人気フレームワークの両方を使用してインテリジェントエージェントを作成します。これにより、ツールの利用について推論し、マルチステップのワークフローを実行して、複雑なビジネス機能に対する自然言語インターフェースを提供できるようにします。

**本番アプリケーションのデプロイ (Deploy production applications)**:: 推論、ツール、MCP、トレース、評価、フィードバックを統合した Web ベースのチャットインターフェースを持つフルスタック AI エージェントアプリケーションをデプロイして、本コースを締めくくります。

== ラボアーキテクチャ (Lab architecture)

image::lab_diagram.png[]

本ワークショップを通じて、OpenShift 上で動作する以下のエンタープライズ AI アーキテクチャを扱います：

* **Llama Stack Distribution**: 推論、エージェント、RAG、ツールのための統合 API を提供する中核となる AI プラットフォーム
* **vLLM**: Qwen3 14B モデル、Llama Scout 17B、Llama Guard 3 1B などを使用した高性能モデルサービング
* **MCP サーバー (MCP Servers)**: エージェントをバックエンドシステムに接続するプロトコル変換層
* **バックエンドマイクロサービス (Backend Microservices)**: 顧客および財務機能を提供する PostgreSQL バックエンドの REST API
* **エージェントアプリケーション (Agent Applications)**: さまざまなエージェントアーキテクチャやフレームワークを実証する Python アプリケーション

すべてのコンポーネントは Red Hat OpenShift AI 3 上で動作し、本番環境向け AI ワークロードに対応したエンタープライズグレードのインフラストラクチャを活用します。

== ワークショップモジュール (Workshop Modules)

1. **はじめに (Introduction)**（本モジュール）- ワークショップの概要と目的
2. **Llama Stack のデプロイ (Deploying Llama Stack)** - AI プラットフォームのインストールと設定
3. **Llama Stack の探索 (Exploring Llama Stack)** - API の探索と推論機能のテスト
4. **RAG** - ドキュメント検索とナレッジのグラウンディングの実装 *オプショナル*
5. **評価 (Evals)** - モデルからのレスポンスの評価 *オプショナル*
6. **シールド (Shields)** - セーフティとコンテンツモデレーションの適用 *オプショナル*
7. **Web 検索 (Web Search)** - Tavily を使用した Web 検索結果によるコンテキスト拡張 *オプショナル*
8. **バックエンドのセットアップ (Backend Setup)** - マイクロサービスと MCP サーバーのデプロイ
9. **MCP** - MCP 経由でビジネス機能ツールを使用する Python エージェントの構築
10. **エージェント (Agent)** - Llama Stack Agent API の探索
11. **エージェント (Agent)** - 完全な LangGraph ベースのエージェントアプリケーションのデプロイ
12. **トレース (Traces)** - トレース、評価、フィードバックのための Langfuse の使用
13. **ワークベンチ (Workbench)** - RHOAI 内に組み込まれたクラスター内・ブラウザ内 VS Code *オプショナル*

本ワークショップの最後までに、Llama Stack、FastMCP、LangGraph、FastAPI、Langfuse、およびエンタープライズインフラストラクチャを使用し、OpenShift 上で Agentic AI システムを構築、デプロイ、運用するハンズオン経験を得ることができます。
