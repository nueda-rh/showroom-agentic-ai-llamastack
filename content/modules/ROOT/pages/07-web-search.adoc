Llama Stack の Web 検索 (Web Search with Llama Stack)

Llama Stack の標準機能で最も強力なツールの一つが **Web 検索 (web search)** であり、これは link:https://www.tavily.com/[Tavily^] と統合されています。

これにより、エージェントやアプリケーションは、トレーニングデータだけに頼ることなく、インターネット上のソースから最新かつ最高の情報を入手できるようになります。

[TIP]
====
**Tavily とは何ですか？** Tavily は、LLM アプリケーション向けに特別に設計された AI 最適化検索エンジンです。生の HTML を返す一般的な Web 検索 API とは異なり、Tavily はモデルが直接推論できるクリーンで構造化されたコンテンツを返します。無料枠でも、開発やテストに十分な API 呼び出しが可能です。
====

有効にするには Tavily の API キーが**必要**です。link:https://www.tavily.com/[www.tavily.com^] でサインアップして API キーを作成してください。

image::tavily.png[]

=== 最後のスーパーボウルで優勝したのは誰ですか？ (Who won the last Super Bowl?)

Response API を使用して、最後のスーパーボウルで誰が優勝したかを尋ねるコードスニペットを確認してください。

````python
# クライアントを初期化
client = LlamaStackClient(base_url=LLAMA_STACK_BASE_URL)

# Web 検索なしでレスポンスを作成（非ストリーミング）
response = client.responses.create(
    model=INFERENCE_MODEL,
    input="Who won the last Super Bowl?",
    stream=False,
)
````

Web 検索を使用**せず**、モデルのトレーニングデータのみを使用してスクリプトを実行します。

[.console-input]
[source,bash,role="copypaste",subs=attributes+]
----
python 2_no_web_search.py
----

[.console-output]
[source,text,subs=attributes+]
----
最後のスーパーボウルである **第58回スーパーボウル (Super Bowl LVIII)** は、**2024年2月11日**にラスベガスのアレジアント・スタジアムで開催されました。**カンザスシティ・チーフス**が **25-22** のスコアで **サンフランシスコ・フォーティナイナーズ**を破りました。

チーフスの **パトリック・マホームズ** が **スーパーボウル MVP** に選ばれ、強力なパフォーマンスでチームを勝利に導きました。これは、チーフスにとって 3 年間で 2 度目（2020年の勝利に続く）のスーパーボウル制覇となりました。
----

非確定的な LLM を扱っているため、受け取る回答は上記とは異なる場合があります。通常、回答には 2023 年または 2024 年の勝者が含まれます。

[NOTE]
====
**なぜ回答が古いのですか？** モデルのトレーニングデータにはカットオフ日（Qwen3 の場合は通常 2024 年半ば）があります。トレーニング中に学習した内容に基づいてしか回答できません。そのカットオフ後の出来事（2025 年 2 月の第 59 回スーパーボウルなど）は、外部ツールなしではモデルには見えません。
====

次に、組み込みツールを使用して Tavily Web 検索を使用し、**より最新の回答を受け取れる可能性**を高めます。

以下のスニペットを確認してください。

````python
# Tavily API キーを使用してクライアントを初期化
client = LlamaStackClient(
    base_url=LLAMA_STACK_BASE_URL,
    provider_data={"tavily_search_api_key": TAVILY_SEARCH_API_KEY} if TAVILY_SEARCH_API_KEY else None,
)

# Web 検索を使用してレスポンスを作成（非ストリーミング）
response = client.responses.create(
    model=INFERENCE_MODEL,
    input=QUESTION,
    tools=[{"type": "web_search"}],
    stream=False,
)
````

スクリプトを実行します。

[.console-input]
[source,bash,role="copypaste",subs=attributes+]
----
QUESTION="Who won the last Super Bowl?" python 3_web_search.py
----

注：2026 年 2 月 8 日以降にこのクエリを実行している場合は、おそらく異なる回答が返されます。

[TIP]
====
**どのように動作しますか？** `tools=[{"type": "web_search"}]` が指定されると、Llama Stack は回答する前に Tavily を呼び出すようモデルに指示します。Tavily は Web を検索し、関連するスニペットを返し、モデルはその最新の情報を回答に取り込みます。コードでは、Llama Stack が検索サービスで認証できるように、`provider_data` を介して Tavily API キーも渡していることに注目してください。
====

[.console-output]
[source,text,subs=attributes+]
----
Tavily Key: セット完了
質問: Who won the last Super Bowl?

フィラデルフィア・イーグルスが直近のスーパーボウル（2025年の第59回スーパーボウル）で優勝し、ニューオーリンズでカンザスシティ・チーフスを **40-22** のスコアで破りました。これはイーグルスにとって 2 度目のスーパーボウル制覇であり、2018年以来の優勝となりました。

====

=== 今日 (Today)

検索結果を向上させるための重要なヒントは、すべてのプロンプトに **「今日 (Today)」** を追加することです。

----
today = date.today()
prompt=f"Today is {today}. Who is the current US President?"
----

今日の目的の日付を知るだけで、「現在 (current)」、「第2四半期 (Q2)」、「昨年 (last year)」といった時間的な性質を持つ事柄についてモデルが推論するのに役立ちます。

[TIP]
====
**シンプルだが強力なパターン:** すべてのプロンプトの先頭に `Today is {date}` を追加することは、低コストで効果の高い手法です。これにより、モデルは「現在」（Web 検索が必要）と「過去」（トレーニングデータで十分）を区別できるようになり、Tavily もより関連性の高い、時期に合った結果を返すことができます。本番環境のプロンプトテンプレートの標準的な一部として検討してください。
====

[.console-input]
[source,bash,role="copypaste",subs=attributes+]
----
python 5_web_search_president_today.py
----

[.console-output]
[source,text,subs=attributes+]
----
2026年1月8日現在、現在のアメリカ大統領は **ドナルド・トランプ** です。
ニュース記事やホワイトハウスの公式ウェブサイトを含む複数の情報源が示すように、
彼は2024年の選挙で2期目を獲得しました。
----

### 回答 (Responses)

Responses API を介して Web 検索ツールを使用することもできます。

[.console-input]
[source,bash,role="copypaste",subs=attributes+]
----
QUESTION="Who won the last Super Bowl?"

cat << EOF | curl -sS "$LLAMA_STACK_BASE_URL/v1/responses" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $API_KEY" \
    -H "X-LlamaStack-Provider-Data: {\"tavily_search_api_key\": \"$TAVILY_SEARCH_API_KEY\"}" \
    -d @- | jq -r '.output[] | select(.type == "message") | .content[0].text'
{
  "model": "$INFERENCE_MODEL",
  "input": "Today is $(date +%Y-%m-%d). $QUESTION",
  "tools": [{"type": "web_search"}],
  "stream": false
}
EOF
----

== まとめ (Summary)

このモジュールでは以下のことを行いました。

* Web 検索の**あり・なし**でモデルの回答を比較し、トレーニングデータのカットオフによって回答が古くなる様子を確認しました。
* Llama Stack の組み込み `web_search` ツールを介して Tavily を使用し、最新情報を取得しました。
* モデルの **知識カットオフ日 (knowledge cutoff date)** を知ることの重要性を学びました。
* 時間的推論と検索の関連性を向上させるために、**"Today is..."** プロンプトパターンを適用しました。
* Python SDK と直接の REST API 呼び出しの両方から Web 検索にアクセスしました。

Web 検索はエージェントに追加できる最もシンプルなツールの一つであり、LLM に対する最も一般的な不満の一つである「情報の古さ」を即座に解決します。
