= ワークショップ詳細：Llama Stackとサードパーティ製フレームワークによるエージェンティックAI

[.lead]
このハンズオンワークショップでは、Red Hat OpenShift上のLlama Stackを使用して、本番環境に対応したエージェンティックAIアプリケーションの構築について探求します。参加者は、完全なAIエージェントスタックをデプロイおよび構成し、Model Context Protocol（MCP）を通じて外部データソースを統合し、顧客システムや財務システムとリアルタイムで対話できるインテリジェントなエージェントを構築します。

== 対象となるRed Hat製品

* Red Hat OpenShift
* Red Hat OpenShift AI

== 想定受講者

  このワークショップは、次世代のAIを組み込んだアプリケーションを構築したいAIエンジニアおよびアプリケーション開発者を対象としています。参加者には以下のことが求められます：
  - Pythonプログラミングに関する基本的な知識
  - Kubernetes/OpenShiftの概念（ポッド、サービス、ルート）の理解
  - LLM、エージェンティック・ワークフロー、およびツール呼び出しパターンへの関心
  - REST APIおよびコンテナ化されたアプリケーションの経験

== ラボのハイライト

  - LlamaStackDistributionオペレーターとOpenShift AIを使用してOpenShift上にLlama Stackをデプロイする
  - Llama Stackの包括的なAPIサーフェス（チャット補完、レスポンス、ツールランタイム）を探索する
  - MCPサーバーを登録および構成し、カスタムツールでエージェントの機能を拡張する
  - ネイティブのLlama StackクライアントとLangGraphフレームワークの両方を使用してエージェントを構築する
  - 顧客検索と財務取引ワークフローをオーケストレートするマルチツールエージェントを構築する
  - Helmチャートを使用して、WebベースのチャットUIを備えた本番環境対応のエージェントをデプロイする
