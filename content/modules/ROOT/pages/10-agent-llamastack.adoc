= エージェント - Llama Stack

== はじめに (Introduction)

このモジュールでは、Llama Stack の強力なエージェントフレームワークを使用してインテリジェントエージェントを構築する方法を学びます。エージェントとは、単なる質問への回答を超えて、複雑なタスクを達成するために推論し、意思決定を行い、アクションを実行できる自律的な問題解決者としての AI システムです。

このハンズオン演習を通じて、慎重に構成されたステップを進めていきます。

* **はじめに (Getting Started)**: シンプルな「Hello World」エージェントから始めて、標準レスポンスとストリーミングレスポンスの両方を含む、基本的なエージェントの作成と実行パターンを理解します。

* **ツールとの連携 (Working with Tools)**: 組み込み機能や、顧客データベースや財務サービスなどの実際のビジネスシステムと対話するカスタムツールに接続することで、エージェントが真に強力になる方法を確認します。

* **MCP 統合 (MCP Integration)**: 前のモジュールで学んだ MCP の知識に基づき、モデルコンテキストプロトコル (Model Context Protocol) サーバーをツールプロバイダーとして統合し、エージェントが豊富で構造化されたデータソースにアクセスできるようにします。

* **高度なエージェントパターン (Advanced Agent Patterns)**: 異なるシステム間を調整するマルチツールエージェント、コンテキストを維持するマルチターン対話、AI の自律性と人間の監視を組み合わせたヒューマンインザループ (human-in-the-loop: HITL) ワークフローなど、高度なパターンを探索します。

このモジュールの終わりには、Llama Stack の本番環境に対応したエージェントフレームワークを使用して、データベースへの自律的なクエリ、財務データの処理、および複数のビジネスドメインにわたるインテリジェントな対話が可能なエージェントを構築する実務経験を得ることができます。

それでは、環境をセットアップして最初のエージェントを実行しましょう。

以下のスニペットを確認して、エージェントが単一の MCP サーバーを使用してメールアドレスから顧客情報を検索する様子を見てみましょう。

[source,python]
----
# Initialize client
client = LlamaStackClient(base_url=LLAMA_STACK_BASE_URL)

# Configure MCP tools
mcp_tools = [
    {
        "type": "mcp",
        "server_url": CUSTOMER_MCP_SERVER_URL,
        "server_label": "customer",
    }
]

# Create an agent with MCP tools
agent = Agent(
    client,
    model=INFERENCE_MODEL,
    instructions="You are a helpful assistant that can search for customer information using the available tools.",
    tools=mcp_tools,
)

# Create a session
session_id = agent.create_session(session_name="customer_search_session")

# Create a turn to search for a customer by email
response = agent.create_turn(
    session_id=session_id,
    messages=[{"role": "user", "content": "tell me about the customer with the email address thomashardy@example.com"}],
    stream=False,
)
----

[TIP]
====
**エージェント vs 直接的なツール呼び出し:** 前のモジュールでの Llama Stack クライアントのアプローチと比較してください。ここでは、エージェントに自然言語の指示（「メールアドレス...の顧客について教えて」）を与えると、エージェントがどのツールを呼び出し、結果をどのようにフォーマットするかを決定します。エージェントはセッションとターンを管理し、インタラクション全体でコンテキストを維持します。
====

== まとめ (Conclusion)

このモジュール全体を通して、シンプルな「Hello World」エージェントの構築から、実際のビジネスデータと自律的に対話できる高度で本番環境に対応した AI システムの作成まで進んできました。Llama Stack のエージェントフレームワークが、ツールや MCP サーバーと接続することで、言語モデルを受動的な応答者から能動的な問題解決者へと変える様子を確認しました。単一ツールのエージェントからマルチターンのヒューマンインザループ対話への過程は、エージェント型 AI パラダイムの汎用性とパワーを実証しています。Customer および Finance MCP サーバーを統合することで、エージェントはデータベースへのインテリジェントなクエリ、注文履歴の取得、および複数のデータソースの連鎖を、会話コンテキストを維持し自然言語で回答しながら実行できるようになりました。これらのパターンと手法は、カスタマーサービスチームを支援し、ビジネスワークフローを自動化し、組織全体の意思決定を強化できるエンタープライズグレードの AI エージェントを構築するための基盤となります。次のモジュールでは、LangGraph+FastAPI とチャット UI を使用した例を探索します。
