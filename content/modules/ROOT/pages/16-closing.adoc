= 終了

Red Hat OpenShift AI上で、*Llama Stack*、*LangGraph*、*Langfuse*、*FastAPI*、および *FastMCP* を使用してエージェンティックAIアプリケーションを構築するハンズオンワークショップを完了されたことをお祝い申し上げます。最初のLlama Stackインスタンスのデプロイから、Model Context Protocol (MCP) を通じてエンタープライズシステムと対話するAIエージェントの構築まで、一連のプロセスを完了されました。

== 学んだ内容

**Llama Stackのデプロイと探索**:: OpenShift上にLlama Stackディストリビューションをデプロイし、その包括的なAPIランドスケープを探索しました。また、ネイティブのResponse APIを含む複数の推論インターフェースを通じて言語モデルと対話しました。

**RAG機能の提供**:: Llama Stackに組み込まれたベクターストア、埋め込みモデル、およびファイル検索ツールを使用して、AIの回答を独自のドキュメントに基づかせる検索拡張生成 (RAG) システムを構築しました。

**セーフティガードレールの適用**:: AIアプリケーションが企業のセキュリティおよびコンプライアンス要件を確実に満たすようにするための、コンテンツモデレーションとセーフティシールドの実装方法を学びました。

**Web検索ツールの活用**:: モデルの知識のカットオフや限定された学習データを補完するために、Tavilyを使用してコンテキストを拡張しました。

**MCPによるビジネスシステムとの統合**:: Llama StackやLangGraphエージェントをバックエンドのマイクロサービスと橋渡しするModel Context Protocol (MCP) サーバーをデプロイおよび登録し、AIが顧客データ、財務取引、その他のエンタープライズ機能にアクセスできるようにしました。

**自律型エージェントの構築**:: ネイティブのLlama StackクライアントとLangGraphのような一般的なフレームワークの両方を使用して、ツールの使用方法を推論し、多段階のワークフローを実行し、複雑なビジネス機能に対して自然言語インターフェースを提供できるインテリジェントなエージェントを作成しました。

**本番アプリケーションのデプロイ**:: 推論、ツール、MCP、トレース、評価、およびフィードバックを統合した、Webベースのチャットインターフェースを備えたフルスタックのAIエージェントアプリケーションをデプロイすることで、一連のプロセスを締めくくりました。

このワークショップを通じて、OpenShift上で動作するエンタープライズAIアーキテクチャを使用して作業を行いました。

* **Llama Stackディストリビューション**: 推論、エージェント、RAG、およびツールのための統合APIを提供するコアAIプラットフォーム
* **vLLM**: Qwen3 14Bモデル、Llama Scout 17B、Llama Guard 3 1Bなどを使用した高性能なモデルサービング
* **MCPサーバー**: エージェントをバックエンドシステムに接続するプロトコル変換レイヤー
* **バックエンドマイクロサービス**: 顧客および財務機能を提供するPostgreSQLベースのREST API
* **エージェントアプリケーション**: さまざまなエージェントアーキテクチャとフレームワークを示すPythonアプリケーション

すべてのコンポーネントは Red Hat OpenShift AI 3 上で動作し、本番環境のAIワークロード向けにエンタープライズグレードのインフラストラクチャを活用しました。

== 完了したワークショップモジュール

1. **はじめに (Introduction)** - ワークショップの概要と目的
2. **Llama Stackのデプロイ (Deploying Llama Stack)** - AIプラットフォームのインストールと構成
3. **Llama Stackの探索 (Exploring Llama Stack)** - APIの発見と推論機能のテスト
4. **RAG** - ドキュメント検索と知識ベースの回答の実装
5. **評価 (Evals)** - モデルからの回答の評価
6. **シールド (Shields)** - セーフティとコンテンツモデレーションの適用
7. **Web検索 (Web Search)** - Web検索結果によるコンテキストの拡張
8. **バックエンドのセットアップ (Backend Setup)** - マイクロサービスとMCPサーバーのデプロイ
9. **MCP** - MCPを介してビジネス関数ツールを使用するPythonエージェントの構築
10. **エージェント (Agent)** - Llama Stack Agent APIの探索
11. **エージェント (Agent)** - LangGraphベースの完全なエージェントアプリケーションのデプロイ
12. **トレース (Traces)** - トレース、評価、フィードバックへのLangfuseの活用
13. **Langflow** - グラフィカルなエージェントワークフローの構築
14. **Workbench** - OpenShift AIのクラスター内ブラウザベースVS Codeの探索

これで、Llama Stack、FastMCP、LangGraph、FastAPI、Langfuse、Langflow、およびエンタープライズインフラストラクチャを使用して、OpenShift上でエージェンティックAIシステムを構築、デプロイ、および運用するハンズオンの経験を得られました。
