== AIラボアシスタント (AI Lab Assistant)

image::ai-assistant-icon.png[AI Lab Assistant]

本ワークショップ期間中は、マテリアルの学習、質問への回答、トラブルシューティングをサポートするAI搭載のラボアシスタントを利用できます。アシスタントはドキュメントに直接統合されており、ワークショップの内容、OpenShiftの操作、本ラボで扱う技術に関する知識を備えています。

AIアシスタントは以下の点で役立ちます：

* *技術についての質問* - Llama Stack、RAG、エージェント、MCP、その他ワークショップで扱う任意の技術について詳しく学ぶ
* *トラブルシューティングのアドバイスの取得* - 問題が発生した際、起きている現象を説明してください。「演習4でLlamaStackサーバーをデプロイしましたが、アクセスしようとすると404エラーが発生します」や「自分のプロジェクト内のllamastackデプロイメントの何が問題ですか？」のように具体的に記述してください
* *ワークショップの手順の明確化* - ワークショップのいずれかのステップが不明確な場合、明確化や追加コンテキストの提供を求める
* *OpenShiftリソースの理解* - Pod、Deployment、Service、Route、その他のKubernetes/OpenShiftの概念に関するヘルプを受ける

最適な結果を得るために、質問は明確かつ具体的に行ってください。取り組んでいる演習、試したこと、確認されたエラーメッセージや予期しない挙動などの詳細を含めてください。
